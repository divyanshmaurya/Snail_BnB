## AI Assistant (小蝸) — fully Gemini-powered

Floating widget bottom-right (`js/assistant.js`) backed by one serverless function (`api/assistant.js` → `/api/assistant`). Every reply is generated by Gemini — there is no canned-answer fallback; API failures show an honest error message with a Retry button.

- **Chat** (`action: "chat"`): Gemini with a brand system prompt (all guesthouse facts + the 5 spec FAQs) and conversation history for context. Answers in the visitor's language.
- **Continuous voice conversation** (`action: "voice"`): one mic tap enters voice mode — the widget listens continuously, shows a live caption while you speak (Web Speech API where available, display-only), detects end-of-utterance by silence (VAD on the mic's RMS level), auto-sends the recording (Web Audio → 16 kHz mono WAV) to Gemini's multimodal endpoint (transcript + reply in one structured-JSON call), plays the spoken reply, then resumes listening. No send button needed; tap the mic again to exit. Mic input is paused during playback to avoid the assistant hearing itself.
- **Voice replies** (`action: "tts"`): Gemini's TTS model (`gemini-2.5-flash-preview-tts`, voice `Kore`) generates speech (PCM wrapped into WAV server-side). Playback uses a single `<audio>` element unlocked on the first user tap so iOS Safari plays it reliably; if Gemini TTS fails (e.g. rate limit) the browser's speech synthesis speaks the reply instead, so voice output is consistent. The speaker toggle enables spoken replies for typed questions.
- **Single-language replies**: the system prompt carries a highest-priority rule (plus a per-request directive from the site's current language) to answer in exactly one language — no mixed-language or duplicated bilingual replies.
- **Mobile-safe layout**: 16 px input font (prevents iOS Safari focus-zoom that clipped the send button), safe-area insets and `dvh` panel height on small screens.
- **Bilingual**: greeting, suggestion chips and error messages follow the site language.

Environment variables (Vercel → Settings → Environment Variables): `GEMINI_API_KEY` (required), `GEMINI_MODEL` (default `gemini-2.5-flash`), `GEMINI_TTS_MODEL` (default `gemini-2.5-flash-preview-tts`), `GEMINI_TTS_VOICE` (default `Kore`).

## Language toggle

An `EN / 中文` button in the top-right of the navbar switches the whole site between Traditional Chinese (default) and English — static copy via `data-i18n` attributes (`js/i18n.js`), dynamic content (rooms, reviews, chatbot) re-renders on the `langchange` event. Choice persists in `localStorage`.

## Deploying to Vercel

1. Import the GitHub repo at vercel.com/new (Framework Preset: **Other**; no build command or output directory needed).
2. In **Settings → Environment Variables**, add `GEMINI_API_KEY` with your Google AI Studio key (optional overrides: `GEMINI_MODEL`, `GEMINI_TTS_MODEL`, `GEMINI_TTS_VOICE`).
3. Deploy. Static files are served as-is and `api/assistant.js` becomes the `/api/assistant` function automatically.

Local development with the function: `npx vercel dev` (a plain static server works for the page, but the assistant needs the function + key).

## Images

Professional real-estate theme with photographic imagery. All photos are Unsplash placeholder stock loaded from `images.unsplash.com` (marked `待換 AI 生成圖` in the HTML) — swap the URLs for AI-generated brand photos before the client preview. Every image has an `onerror` fallback (neutral block) so a broken URL never shows a broken-image icon; the hero and events-band backgrounds have solid fallback colors underneath.

## Tech & running

Plain HTML/CSS/vanilla JS, no build step. Open `index.html`, or:

```bash
python3 -m http.server 8000
```
